# 재재이야

서울 재개발·재건축 구역을 실제 지도 경계로 찾고, 진행 단계·실거래·규제 근거를 읽으며 내 조건으로 분담금과 총투자금을 계산하는 정적 웹 도구입니다.

## 링크로 쓰기

GitHub Pages의 `/jaejae/`에서 `site/index.html`을 첫 화면으로 엽니다. 설치·가입·서버 실행은 필요 없습니다. 구역 이름 검색, 구역 지도, 재재 지식, 계산기 네 탭을 이용할 수 있습니다.

폴더를 내려받아 `site/index.html`을 직접 열어도 작동합니다. `file://`에서는 JSON과 동일한 자료의 JS 전송 사본을 읽습니다. 인터넷이 없으면 외부 글꼴 대신 시스템 글꼴을 사용하며 지도 타일은 보이지 않을 수 있습니다.

## 배포 설정

빌드 도구와 프레임워크가 없습니다. `.github/workflows/pages.yml`은 `main` 푸시 시 `site/`만 Pages에 올립니다. 저장소 설정에서 Pages 원본을 GitHub Actions로 지정하세요.

선택 비밀값 `VWORLD_KEY`가 있으면 배포 때만 별도 `vworld_key.js`를 만들고 연결합니다. 없으면 OpenStreetMap을 사용합니다. 열쇠 파일·DB·`.env`는 저장소에 넣지 않습니다. 로컬에서 선택 키 파일을 따로 만들 경우 `zone.html`의 `basemap-config.js` 앞에 해당 파일을 연결하세요. 원본 지먹의 키를 복사하지 않습니다.

## 자료와 범위

- 구역·단계·공급 계획: 서울시 정비사업 정보몽땅 기존 수집본, 2026-11-04.
- 경계: 서울 열린데이터광장 OA-22712, 18b 원좌표 514곳·50,359점. 경계 없는 188곳은 이름표만 표시합니다.
- 빌라·단독·토지 추이: 2026-11-06 기준, **법정동 기준 근사·구역 주소 법정동 기준**입니다. 구역 안 집계가 아닙니다.
- 주변 아파트 거래: 기존 SQLite에서 대표점 반경 1km·최근 24개월만 구역별 파일로 추출합니다. 미수집 자치구는 수집 범위 밖입니다.
- 규제: 원문 근거 확인일 2026-11-06. 이후 추가 지정·해제는 관계 부처 공고로 확인해야 합니다.
- 질문·답과 조문: 2026-11-04 저장 자료. 예외 문장은 최신 원문 재대조 전 참고입니다.

자료별 링크와 이용 조건은 `site/출처.html`에 있습니다. 첫 화면 사진은 AI 생성 예시입니다. 실시간 갱신 서비스가 아닙니다.
